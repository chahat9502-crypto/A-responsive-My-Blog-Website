# Responsive Web Design

A modern and responsive **Web Design Project** built using **HTML, CSS, and JavaScript**.

The website is designed to provide a clean and user-friendly experience across different screen sizes, including desktops, tablets, and mobile devices.

## Features

* Fully responsive design
* Mobile-friendly layout
* Clean and modern user interface
* Responsive navigation menu
* Smooth scrolling
* Interactive buttons and elements
* Hover effects and animations
* Optimized layout for different screen sizes
* Cross-device compatibility

## Technologies Used

* HTML5
* CSS3
* JavaScript

## How to Run

1. Download or clone this repository.
2. Open the project in VS Code.
3. Open `index.html`.
